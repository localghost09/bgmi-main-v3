OBS source setup

Ten event-inspired layouts, with real transparent camera/gameplay openings. The browser draws only graphics. Your phone, game and caster video sources stay in OBS.

Use a 1920×1080 OBS canvas and a 1920×1080 Browser Source at 30 or 60 fps. Put this browser source above the capture sources. Copy the clean obs=1 URL from the producer. Do not add a black background or chroma-key the browser.

1 · Caster cameras

Select your event theme, choose Casters, then click OBS source guide in the producer. The guide displays each camera's x/y/width/height at full-HD scale. Resize/crop your two OBS video sources into those windows. The checkerboard is a browser-only guide, not a broadcast background. Camera coordinates vary by theme.

Use the same guide for Match drop; it has its own camera positions and an actual 30-second clock. Restart the Browser Source or press R in the stage tab to reset the clock.

2 · Countdown → map animation → gameplay

Set the opening countdown in the producer’s Stream Starting timer (minutes:seconds) box. Enter 5:30 for five minutes and thirty seconds, then click Apply / restart timer. It saves on the server and restarts open Stream Starting overlays—no URL editing. Valid range: 0:01 to 999:59.

At zero, the drop scene moves to an 8-second map deployment animation, then to the diagonal live scene. The current live match selects Erangel, Miramar or Rondo. You can override it in the producer's map menu. The stream-start clock respects the full configured duration, including when auto-show is on.

The original sample-free instrumental sting is dedicated under CC0. Enable Original CC0 intro music in the producer. In OBS Browser Source properties, enable Control audio via OBS, then set its mixer level. Music stops when leaving the map intro. If a normal browser blocks autoplay, use the “Enable intro music” button on the interactive stage. audio=0 mutes it.

3 · Rectangular gameplay + tactical map

This scene has no points table and no diagonal cut. The two separate rectangular frames are staggered diagonally across the canvas: map at top-right, larger gameplay at bottom-left. Match/event information stays upper-left; sponsor text stays bottom-right. Both video apertures are transparent.

Use OBS Edit Transform to fit each capture to these bounds on a 1920×1080 canvas, then crop/scale the source content as needed. The 3px browser frame covers the capture edge. Place the Browser Source above both captures. Remove the old diagonal Image Mask/Blend filters; no masks are needed for these rectangles. Add your own background image below the captures if you want a studio backdrop in the unused space.

4 · Main gameplay + live standings

Switch to Live points. Use the full-screen phone/gameplay capture underneath—no tactical-map capture in this scene. The right standings board has a fully opaque backing; video cannot bleed through it. The rest of the overlay stays transparent.

Use Match Control to update kills and player status. The overlay reads live state and refreshes via SSE; it does not infer knocks from the phone video. Live records are never altered by the showcase simulation.

5 · Finish the show

Winner celebration → winner stats → match standings → overall standings → map rotation remain available. Select them from the producer or the stage controls. Turn off auto-show for real gameplay so the operator decides when the match has ended. Keys 1–9 / 0 keep their original scene assignments; use arrow keys or the map-intro button for the extra bumper.

Assets & reference status

The three maps are actual exports from PUBG's official API-assets repository, not AI maps. These are PUBG PC map exports, not claimed to be BGMI-specific captures. The tactical live scene shows your OBS map feed, not a static exported map.

All ten event themes are original adaptations informed by published event graphics. They are not official broadcast packages, exact replicas, or claims of event affiliation. EWC 2026's available reference is a secondary published PMWC scoreboard; that design remains an interpretation. The legacy overlay shell is unchanged.
