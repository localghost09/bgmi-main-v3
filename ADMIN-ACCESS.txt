IF SIGN-IN "DOES NOTHING"
  Open the app in its own browser tab instead of the embedded preview frame.
  The preview renders pages inside a cross-site iframe, and the browser drops
  the session cookie there unless it is SameSite=None; Secure; Partitioned.
  The server now detects preview hosts (*.e2b.app) and issues exactly that
  cookie, so the frame works too - but a normal tab is the least surprising
  path. A password that is accepted but not remembered now says so on the
  form instead of looping back silently. Add a host to BGMI_PREVIEW_HOSTS
  (comma separated) if you run the preview somewhere else.

TEMPORARY PREVIEW ACCESS
  The running preview was explicitly started with BGMI_ADMIN_LOGIN_BYPASS=1
  at the operator request. No password/cookie is required there. Never use
  this setting on a public deployment; unset it and restart to restore login.
